# Create a playlist

[Repository home](../../README.md) · [Documentation index](../README.md) · [Previous guide](import-music.md) · [Next guide](schedule-programming.md)

## Objective

Create an operator-managed playlist from imported media.

## Prerequisites

Authenticated access and at least one successfully imported media item.

## Procedure

1. Open Playlists in the authenticated interface.
2. Create a playlist and give it a clear operator-facing name.
3. Add imported media using the controls shown for the playlist.
4. Save, then review its order and contents.

## Expected result

The playlist is listed and its media can be selected for programming.

## Verification

Reopen the playlist and confirm the intended items and order remain.

## Troubleshooting

If an item is unavailable, verify that its import and analysis completed first.

## Rollback

Remove the playlist through the same interface only after removing or replacing programming that references it.
