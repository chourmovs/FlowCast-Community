# Known limitations

[Repository home](../../README.md) · [Documentation index](../README.md)
Public OCI images may not yet exist for all tags and architectures, so Compose can validate while pull fails. Endurance, upgrade rollback, rootless Docker, large-library performance, and disaster-recovery qualification are incomplete. Screenshots are not bundled until real rc.7 captures can be reviewed. Community support is best effort and there is no availability SLA. Do not describe this Preview as production-grade.
