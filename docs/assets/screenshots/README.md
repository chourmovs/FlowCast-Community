1. `dashboard-now-playing.png` — authenticated dashboard and Now Playing.

## Safe procedure

1. Install the tagged release on a disposable Linux amd64 host using the README command.
2. Use synthetic test tones and original/generated titles and artwork whose redistribution rights are recorded.
3. Use a browser viewport of at least 1440 × 900 and capture PNG at device scale 1 or 2.
4. Before capture, remove or mask tokens, licence keys, passwords, private IP addresses, machine names, local paths, cookies, personal data and private media.
5. Inspect every pixel at full size; crop browser chrome and optimize losslessly (target under 1 MiB each).
6. Add each verified image, replace the corresponding textual status row in the README with descriptive alt text and a useful caption, and retain this procedure.
7. Have a second maintainer verify that the image is real, current and sanitized.

Never substitute invented UI. If a real capture cannot be made, leave the textual status unchanged and commit no image.
