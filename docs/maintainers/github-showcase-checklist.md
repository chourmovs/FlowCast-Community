# GitHub showcase checklist

[Repository home](../../README.md) · [Documentation index](../README.md)

These repository settings require manual maintainer action:

- [ ] Set the concise repository description to the approved product proposition.
- [ ] Set a homepage only when an official public site exists.
- [ ] Create, rights-review and upload an official social preview when one is available; do not use an unreviewed generated binary.
- [ ] Enable Discussions if community moderation is available.
- [ ] Verify private Security Advisories and reporting are enabled.
- [ ] Verify issue labels/categories and both issue forms.
- [ ] Add topics: `self-hosted`, `radio`, `internet-radio`, `broadcast`, `audio`, `automation`, `rust`, `python`, `icecast`, `gstreamer`, `docker`.
- [ ] Add the four reviewed real-instance screenshots and replace their textual status rows.
- [ ] Review the README on GitHub light/dark themes and at mobile width.
- [ ] Confirm the tagged installation command whenever `VERSION` changes.
