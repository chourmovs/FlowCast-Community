# Contributing

Search existing issues, then open a sanitized bug or proposal. Bug reports must include FlowCast version, OS/architecture, Docker and Compose versions, redacted `doctor.sh` output, reproduction steps, expected behavior, and actual behavior. Never post `.env` files, tokens, passwords, station databases, media, or private URLs.

Fork the repository, create a focused branch, add tests and documentation, run the checks in `README.md`, and submit a pull request. Contributions are licensed under MIT. Support is best effort; security reports follow `SECURITY.md` rather than public issues.
