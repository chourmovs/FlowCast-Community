# Code of Conduct

[Repository home](README.md) · [Documentation index](docs/README.md)

## Our standard

We pledge a harassment-free community regardless of identity, experience or background. Be respectful, constructive, technically honest and mindful of operational safety. Welcome good-faith questions and focus criticism on ideas and reproducible behavior.

Unacceptable behavior includes harassment, threats, discriminatory conduct, doxxing, sustained disruption, impersonation, and publishing another person's credentials, private media or personal data.

## Enforcement

Report conduct privately to the repository maintainers using an appropriate private GitHub channel. Do not disclose sensitive details in a public issue. Maintainers may edit or remove content and temporarily or permanently restrict participation, applying decisions in the community's interests. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
